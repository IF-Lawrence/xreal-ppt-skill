# GPT-M 2.0 配图提示词 · XREAL Style

用于当前 skill 的 XREAL Style 网页 PPT 配图。先确定版式和图片槽位，再生成图片；提示词只负责定基调和规格，不要生成一整张 slide。

## 通用规则

- 视觉锚点：International Typographic Style、Swiss modernism、Josef Müller-Brockmann、Massimo Vignelli
- 字体语境：纯英文 PPT 的配图使用 XREAL Diatype 气质；中文或中英混排 PPT 的配图统一使用 IBM Plex Sans SC 气质，不按图片内的中英文字符混用字体
- 构图：12/16 列网格、左对齐、非对称留白、1px hairline、直角模块
- 色彩：黑、白、灰为主；红色只在关键数据/警示/操作语义中少量出现，银色和金色仅作极少量补充
- 禁止：渐变、阴影、圆角、玻璃拟态、霓虹、3D、卡通、SaaS 模板感、伪 logo、装饰边框
- 图片内部不要出现 PPT 外壳：不要页眉、页脚、页码、标题栏、角标、署名或水印
- 信息图/UI 文字必须短，并跟随 deck 语言；真实照片尽量不要带文字
- 同一页或同一组图片必须保持相同比例、视觉缩放、边距密度和线条粗细
- 生成后保存到 `images/`，命名为 `{页号}-{语义}.{ext}`

## 比例选择

| 用途 | 推荐比例 | HTML 落位 |
|---|---|---|
| S22 Image Hero 顶部横幅 | 21:9 | `.frame-img.r-21x9` |
| 通用主图 | 16:9 | `.frame-img.r-16x9` |
| UI / 信息图 / 截图再设计 | 16:10 | `.frame-img.r-16x10.fit-contain` 或按槽位铺满 |
| 多图网格 | 统一横图 | `.frame-img.h-22` / `.frame-img.h-26` |
| 小型面板组 | 统一横图 | `.frame-img.h-16` / `.frame-img.h-18` |

## 生成前先选槽位

1. 单张主视觉：`s22-hero-21x9`
2. 多图网格：`s15-grid-21x9` 或 `s16-brief-21x9`
3. UI / 信息图：`s15-grid-16x10` 或 `s16-brief-16x10`
4. 证据截图：按实际 frame 选 `21:9` / `16:10`，保真时使用 `.fit-contain`

21:9 图片必须把核心主体放在中央 70% 安全区，四周留白；不要把人脸、关键节点或 UI 文字贴边。

## XREAL Style 类型 1：纪实照片 / 案例主图

用于 S22 Image Hero，增加真实场景锚点。

```text
生成一张 21:9 超宽横向纪实摄影配图，主题是：[页面概念]。风格为 XREAL editorial documentary：高对比、低饱和、冷静克制、真实办公/城市/产品使用场景，大量负空间，主体位于中央 70% 安全区，适合放入 XREAL Style PPT 的顶部横幅。不要 AI 机器人、科幻界面、商业摆拍、logo、水印或文字。只保留核心照片本身，不要页眉、页脚、标题、页码、角标、署名、装饰边框或 PPT 外壳。
```

## XREAL Style 类型 2：信息图 / 系统关系图

用于解释概念、架构、流程、数据与表现分离等抽象内容。

```text
生成一张横向 XREAL Style 信息图，解释：[概念/流程/系统关系]。字体与整套 PPT 语境保持一致：[纯英文使用 XREAL Diatype / 中文或中英混排使用 IBM Plex Sans SC]，不要按标签内的字符语言混用字体。使用无衬线短标签、12/16 列网格、直角模块、1px 发丝线、黑白灰和少量 XREAL 红色语义强调。图中文字使用[中文/英文]，每个标签不超过 8 个字/词。不要渐变、阴影、圆角、3D、卡通、霓虹或 SaaS 模板感。输出比例为[21:9/16:10]，主体居中但保留大留白。只保留核心信息图本身，不要页眉、页脚、标题、页码、角标、署名、装饰边框或 PPT 外壳。
```

## XREAL Style 类型 3：截图再设计 / UI 情景图

用于把截图、工作区、代码或 dashboard 重绘成统一 XREAL Style 视觉。

```text
生成一张横向 UI 情景图，把[截图/界面/工作区内容]再设计成 XREAL Style 视觉。画面使用极简 dashboard / workspace 结构、直角面板、发丝线、12 列网格和少量 XREAL 红色语义强调，无阴影无圆角。图中文字使用[中文/英文]，短而清晰，不要真实品牌 logo。输出必须是 16:10 横向构图，视觉密度中等，适合放进 `.frame-img.r-16x10.fit-contain`。只保留核心 UI 画面本身，不要页眉、页脚、标题、页码、角标、署名、装饰边框或 PPT 外壳。
```

## XREAL Style 类型 4：多图网格单张素材

用于 S15/S16 图片格改造，一组 2-6 张图片并列时逐张生成。

```text
生成一张横向证据图，主题是：[证据 A/B/C]。这是一组 XREAL Style 图片中的一张，请保持直角模块、黑白灰为主、仅在关键语义处使用 XREAL 红色、相同边距、相同线条粗细、相同视觉缩放。图中文字使用[中文/英文]，只保留短标签。输出必须是[21:9/16:10]横向构图，适合放入 S15/S16 统一图片格。只保留核心图像本身，不要页眉、页脚、标题、页码、角标、署名、装饰边框或 PPT 外壳。
```

## XREAL Style 类型 5：极简图表 / 数据块

用于 S21 或 S15/S16 图片格中的小型数据解释图。

```text
生成一张横向 XREAL Style 数据图，核心数据是：[数字/对比/排名]，含义是：[说明]。使用极大无衬线数字、1px 发丝线、直角色块、黑白灰为主，仅用 XREAL 红色突出关键数据，像 XREAL Style 海报里的数据版式。图中文字使用[中文/英文]，只保留必要标签。不要渐变、阴影、圆角、3D 或装饰边框。比例：[16:9/16:10]。只保留核心数据图本身，不要页眉、页脚、标题、页码、角标、署名或 PPT 外壳。
```

## 生成后统一追加

每个提示词末尾补充：

```text
输出必须是[21:9/16:10/16:9]横向构图，主体居中但保留边距，画面密度中等，与同组图片保持相同视觉缩放和边距。只保留核心图形/画面本身，不要生成页眉、页脚、标题、页码、角标、署名、装饰边框、超长条、竖图或不规则比例。
```
